# Video Variator

Пакетна обробка відео: стилі, формати (9:16, 1:1, 4:5, 16:9), водяний знак, текст-хук у стилі CapCut,
покращення якості, пресети. Інтерфейс — CustomTkinter, обробка — FFmpeg.

## Встановлення (Windows 10/11)
1. Натисніть **Code → Download ZIP** і розпакуйте архів.
2. Двічі клацніть **«Запуск.bat»** — він сам встановить Python, FFmpeg і бібліотеки.

Програма сама перевіряє оновлення при запуску (кнопка «⟳ Оновлення» — перевірити вручну).

## Для автора: як випустити оновлення
1. Підніміть `APP_VERSION` у `video_variator.py`.
2. `python tools/publish.py "Що нового"` — оновить `version.json`.
3. Закомітьте й запуште зміни.
